# agrinho-2k26
O site “AGRINHO 2026 – Agro Forte, Futuro Sustentável” foi desenvolvido como um portal educativo interativo com o objetivo de mostrar a relação entre o agronegócio e a preservação ambiental, destacando que produção e sustentabilidade podem caminhar juntas. Ele foi construído utilizando três linguagens principais: HTML, CSS e JavaScript, formando uma estrutura completa de front-end moderno.

A base do projeto é o HTML, responsável pela estrutura do site. Nele, foram criadas diferentes seções como “Início”, “Agro”, “Sustentabilidade”, “Tecnologia”, “Biodiversidade”, “Quiz” e “Contato”. Em vez de criar várias páginas separadas, foi utilizado o conceito de navegação por âncoras internas, onde o menu leva o usuário diretamente para partes específicas da mesma página. Isso é feito com links que apontam para identificadores (id), como por exemplo “#agro” ou “#tecnologia”. Essa técnica torna a navegação mais rápida e fluida, além de facilitar a organização do conteúdo.
O CSS foi utilizado para toda a parte visual do site, sendo responsável pelas cores, tamanhos, animações e disposição dos elementos. O design foi pensado para transmitir a ideia de natureza e tecnologia ao mesmo tempo, utilizando tons de verde, azul e amarelo. Foram aplicados gradientes no cabeçalho para dar um efeito moderno, além de transparência nos cards, criando um estilo visual conhecido como glassmorphism. Também foi utilizada a tecnologia Flexbox para organizar os elementos em formato de grid, permitindo que os blocos se ajustem automaticamente em diferentes tamanhos de tela. Outro recurso importante foi o efeito de zoom nos cards quando o usuário passa o mouse, criando uma sensação de interatividade e dinamismo. Além disso, o site foi projetado para ser responsivo, ou seja, se adaptar a celulares, tablets e computadores.

O JavaScript foi utilizado para adicionar interatividade ao site. Um dos principais recursos foi o quiz educativo, onde o usuário responde perguntas e recebe feedback imediato na tela. Isso é feito por meio de uma função que verifica se a resposta está correta ou incorreta e altera o texto dinamicamente usando manipulação do DOM. Outro recurso utilizado foi a detecção de rolagem da página (scroll), que permite ativar pequenas animações nos elementos à medida que o usuário navega, tornando a experiência mais viva e moderna. O JavaScript também permite que o site responda às ações do usuário em tempo real, sem necessidade de recarregar a página.

projeto utiliza conceitos importantes de design e desenvolvimento web, como hierarquia visual, experiência do usuário (UX) e interface amigável (UI). As cores foram escolhidas para representar a natureza e o campo, enquanto a estrutura em blocos facilita a leitura e compreensão do conteúdo. O site também apresenta elementos modernos como cards interativos, efeitos de hover, seções organizadas e navegação intuitiva.

Em resumo, o site AGRINHO 2026 é um projeto educacional que combina tecnologia e consciência ambiental, utilizando HTML para estrutura, CSS para design visual e JavaScript para interatividade. Ele representa a ideia de um agronegócio moderno, sustentável e tecnológico, mostrando como o desenvolvimento digital pode ser usado para educação e conscientização sobre o futuro do planeta.
